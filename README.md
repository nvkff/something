# Russian Word Clock (Watch Face Format)

Нативный циферблат для Wear OS 4+ (OnePlus Watch, Pixel Watch, Galaxy Watch), отображающий текущее время исключительно русскими словами.

## Особенности
- **Формат:** Официальный Watch Face Format (WFF v1).
- **Энергоэффективность:** Выполняется на сопроцессоре (BES2700), не разряжает батарею в AOD.
- **Совместимость:** Распознается системным лаунчером OnePlus и сразу появляется в меню «+».
- **Шрифт:** `minecraft.ttf` в `app/src/main/res/font/`.
